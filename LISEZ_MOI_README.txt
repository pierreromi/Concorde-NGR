CONCORDE NGR - LISEZ-MOI (francais)                                   English below
====================================

Requis : X-Plane 12.4.4 ou plus recent uniquement, Windows, Concorde FXP de COLIMATA version 3.53.
Cet add-on NECESSITE le Concorde FXP version 3 de COLIMATA (X-Plane 12), vendu separement :
https://store.x-plane.org/Concorde-FXP-version-3--XP12_p_1691.html
NON COMPATIBLE avec X-Plane 11 (le plugin utilise l'interface de X-Plane 12, et le
Concorde FXP v3.53 requis est un avion X-Plane 12).
X-Plane doit etre FERME pendant l'installation.

1. Extraire tout le zip dans un dossier (pas directement dans X-Plane).
2. Lancer installer\installer.bat :
   - il trouve X-Plane 12 et CONCORDE_FXP.acf ;
   - option 1 = ACF original exact (conseille), option 2 = ACF deja modifie ;
   - il ajoute les profils d'aile et la tablette, sauvegarde l'original
     (CONCORDE_FXP.acf.originalconcorde), puis propose de copier le plugin
     Concorde_NGR dans X-Plane 12\Resources\plugins : repondre O.
   Il regle aussi le pilote automatique (10 reglages, plus de installer_pilote_auto.bat depuis la V1.1).
3. Demarrer X-Plane, charger le Concorde FXP, batterie 1 ou 2 sur ON : le MCDU s'allume.
4. Notice d'emploi : ouvrir notice\NOTICE_FR.html dans un navigateur (premier vol + toutes les pages).

MODE PURISTE (V1.2) : Plugins > Concorde_NGR > Mode puriste (sans MCDU). Vol sans MCDU (CIVA INS et
carburant a la main) en gardant poussee, trainee et consommation NGR ; voyant TMO = master caution
orange au-dessus de 127 degC au nez. S'applique tout de suite, memorise. Detail : notice, "Mode puriste".

Si Windows bloque un .bat ("Windows a protege votre ordinateur") : cliquer "Informations
complementaires" puis "Executer quand meme". Pour l'eviter : AVANT d'extraire, clic droit sur le zip >
Proprietes > cocher "Debloquer" > OK. Si l'antivirus met un fichier en quarantaine (.bat ou .xpl),
le restaurer et l'autoriser : ces fichiers ne contiennent rien de dangereux.

Desinstaller : installer.bat option 4.
Detail de chaque modification : installer\LISTE_DES_MODIFICATIONS.txt
Bug : indiquer la version d'X-Plane et joindre X-Plane 12\Log.txt.

Profils d'aile CONCORDE_DELTA1_NGR_V5 et CONCORDE_DELTA2_NGR_V5 : creation Concorde NGR (Pierre Romi),
licence Creative Commons BY 4.0 : reutilisation libre, y compris dans un add-on payant,
a condition de citer "Concorde NGR - Pierre Romi".


CONCORDE NGR - README (English)
===============================

Required: X-Plane 12.4.4 or later only, Windows, COLIMATA Concorde FXP version 3.53.
This add-on REQUIRES the COLIMATA Concorde FXP version 3 (X-Plane 12), sold separately:
https://store.x-plane.org/Concorde-FXP-version-3--XP12_p_1691.html
NOT COMPATIBLE with X-Plane 11 (the plugin uses the X-Plane 12 interface, and the required
Concorde FXP v3.53 is an X-Plane 12 aircraft).
X-Plane must be CLOSED during installation.

1. Extract the whole zip into a folder (not directly into X-Plane).
2. Run installer\installer.bat:
   - it finds X-Plane 12 and CONCORDE_FXP.acf;
   - option 1 = exact original ACF (recommended), option 2 = already modified ACF;
   - it adds the airfoils and the tablet, backs up the original
     (CONCORDE_FXP.acf.originalconcorde), then offers to copy the Concorde_NGR
     plugin into X-Plane 12\Resources\plugins: answer Y.
   It also sets the autopilot (10 settings, no more installer_pilote_auto.bat since V1.1).
3. Start X-Plane, load the Concorde FXP, battery 1 or 2 ON: the MCDU powers up.
4. User manual: open notice\NOTICE_EN.html in a web browser (first flight + every page).

PURIST MODE (V1.2): Plugins > Concorde_NGR > Purist mode (no MCDU). Fly without the MCDU (CIVA INS and
fuel by hand) while keeping NGR thrust, drag and fuel burn; TMO light = orange master caution above
127 degC at the nose. Applies at once, remembered. Details: manual, "Purist mode".

If Windows blocks a .bat ("Windows protected your PC"): click "More info" then "Run anyway".
To avoid it: BEFORE extracting, right-click the zip > Properties > tick "Unblock" > OK.
If your antivirus quarantines a file (.bat or .xpl), restore and allow it: these files are harmless.

Uninstall: installer.bat option 4.
Details of every change: installer\LIST_OF_CHANGES.txt
Bug: give your X-Plane version and attach X-Plane 12\Log.txt.
