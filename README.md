# Concorde NGR

Free MCDU, managed autopilot and crew voice plugin for the **Colimata Concorde FXP** in **X-Plane 12** (Windows).
This repository contains the **release packages only** (no source code).

## Install
1. Download this repository (green **Code** button > **Download ZIP**) or a zip from **Releases**.
2. Read `LISEZ_MOI_README.txt`, then run `installer\installer.bat`.
3. User manual: `notice\NOTICE_EN.html`.
