CONCORDE NGR - LIST OF CHANGES MADE BY installer.bat
========================================================================
Aircraft: Colimata Concorde FXP (X-Plane 12), file CONCORDE_FXP.acf
Reference original ACF: MD5 2a219391158d87e35bd5304b46c69254

1. WHAT THE .BAT DOES
  - Checks that X-Plane is closed, finds X-Plane 12 and CONCORDE_FXP.acf.
  - Backs up CONCORDE_FXP.acf as CONCORDE_FXP.acf.originalconcorde (once, never overwritten).
  - Copies the files below (section 2). An existing different file is backed up as .originalconcorde.
  - Changes the ACF lines below (section 3). Nothing else in the ACF is touched.
  - The ACF file is rewritten with Windows line endings (CRLF): no effect for X-Plane.
  - Adds the MCDU screen to CONCORDE_FXP_cockpit.obj (options 1 and 2): 4 vertices, 6 indices, one 12-line block,
    POINT_COUNTS +4 / +6 (data: ecran_cockpit.txt). Backup CONCORDE_FXP_cockpit.obj.originalconcorde.
    The screen must be in the cockpit object: X-Plane only sends clicks to the plugin for that object.
  - Records what it did in CONCORDE_FXP\ngr_installe.txt (used for uninstall).
  - Offers (yes/no) to copy the Concorde_NGR plugin into X-Plane 12\Resources\plugins\.

  Menu: 1 automatic install (exact original ACF only)
         2 force key by key (other ACF version or already modified; missing lines are reported)
         3 copy the files only, the ACF is edited BY HAND with this list
         4 uninstall (restores the .originalconcorde ACF and cockpit, removes added files, plugin optional)

4. DOING IT BY HAND (option 3)
  a. Close X-Plane. Copy CONCORDE_FXP.acf to CONCORDE_FXP.acf.originalconcorde (backup).
  b. Open CONCORDE_FXP.acf with a text editor (Notepad, Notepad++).
  c. For each line of section 3: search "P key " and replace the value.
  d. Tablet: read the value of "P _obja/count" (N, 44 in the original). Add the 13 block lines
     replacing 44 with N, after the last "P _obja/N-1/..." line, then set "P _obja/count" to N+1.
  e. Save. Copy the files of section 2 (CONCORDE_FXP folder of the package).
  f. Screen: copy CONCORDE_FXP_cockpit.obj to .originalconcorde, then with installer\ecran_cockpit.txt:
     V lines after the last VT; 6 IDX lines N,N+1,N+2,N,N+2,N+3 (N = first POINT_COUNTS number) after the last IDX;
     A lines, then "TRIS I 6" (I = last POINT_COUNTS number), then B lines, after the last ANIM_end;
     finally POINT_COUNTS: N+4 and I+6.
  To undo: put the .originalconcorde files (ACF and cockpit) back in place.
